# AleApp

Aplicação em React para a escola fortec.

## Começando

### Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/0llrayll0-beep/aleapp.git

# Entre na pasta
cd aleapp

# Instale as dependências
npm install

# Rode o projeto
npm run dev
